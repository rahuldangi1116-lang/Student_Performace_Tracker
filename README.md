
# Student Performance Prediction

## 1. Project Overview

Student Performance Prediction is a Machine Learning
project based on Supervised Learning and Regression.

The application predicts students' examination marks
using academic and personal factors.

## 2. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib

## 3. Machine Learning Algorithms

The project can compare:

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

The trained model is saved as a Pickle file.

## 4. Input Features

- Hours Studied
- Attendance
- Previous Scores
- Sleep Hours
- Tutoring Sessions
- Physical Activity
- Parental Involvement
- Access to Resources
- Motivation Level
- Internet Access
- Family Income
- Teacher Quality
- School Type
- Peer Influence
- Learning Disabilities
- Parental Education Level
- Distance from Home
- Gender
- Extracurricular Activities

## 5. Project Structure

student_performance_streamlit/

    app.py
    predictor.py
    requirements.txt
    README.md

    models/
        student_performance_model.pkl

## 6. Installation

Install dependencies:

    pip install -r requirements.txt

## 7. Run Application

Execute:

    streamlit run app.py

Open browser:

    http://localhost:8501

## 8. Output

The application displays:

- Predicted Examination Marks
- Student Performance Category
- Submitted Student Information

## 9. Project Objective

To use Machine Learning regression techniques
to estimate student examination performance.

## 10. Conclusion

This project demonstrates how supervised
machine learning can be used to predict
student academic performance.
